# Hello world! :wave:

Good day to you kind internet stranger! This is Navid Anindya. A guy who likes making simple stuff.

---

This repository also contains source code to my website. I used AI assistance for parts of the site update.

Used:
* [Nuxt.js](https://nuxtjs.org) - Uses the SSR generate mode.
* [TailwindCSS](https://tailwindcss.nuxtjs.org) - Tailwind CSS.
* [Nuxt Content](https://content.nuxtjs.org/) - For articles.

I used `docker` and `docker-compose` during development. You can also run `npm ci` and `npm run dev` locally. Use `npm run lint` to check the code and `npm run generate` to build the site into `dist`.
